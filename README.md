# Udemy Clone Website

A simple **Udemy Clone Website** built using HTML and CSS. This project is created for practicing basic frontend development and recreating the layout of an online learning platform.

## Features

* Navigation bar
* Search bar
* Course categories
* Sale banner
* Recommended courses
* Popular courses
* Course cards with images, ratings, and prices
* Recommended topics
* Footer section

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
