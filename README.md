# 🎓 Udemy Clone - React

A responsive **Udemy Clone Website** developed using **React.js**.  
This project is an upgraded version of my previous Udemy clone, which was originally built using HTML and CSS. The website has now been converted into a component-based React application for better code organization, reusability, and maintainability.

## 🚀 Live Demo

🔗 [https://udemy-clone-website-seven.vercel.app/](YOUR_VERCEL_URL)

## 📌 Project Overview

This project recreates the basic user interface of an online learning platform inspired by Udemy.

The original version was developed using **HTML and CSS**. In this updated version, the website has been rebuilt using **React.js**, with the interface divided into reusable components.

The project demonstrates the use of React components, JSX, props, reusable UI sections, and a structured React project architecture.
